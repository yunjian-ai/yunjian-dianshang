# 货郎的底子 · 三本会长的账（格式同算盘 v0.1，2026-10-31）

> 给人看：货郎的底子和算盘同一套格式：**A 平台规则库**（官方规则，一条一张卡）、**B 自动化地图**（后台每一步怎么点）、**C 经营决策库**（主人定的规矩，放在主人自己的店铺文件夹里）。规则变了、按钮挪了、规矩改了，都先写变更单再改，旧的不删。脚本里的线和上限一律从账里读，不写死。
> 给 AI：卡的格式、变更单六步照算盘 `库/README.md`（同一套）；这里只写货郎自己的东西。

## 文件夹（装好以后在 `~/.yunjian/hawk/`）
```
库/                    我们给的，更新时整份换新
  平台规则库/          R-SP（商品和上架）、R-LM（精选联盟）卡；变更记录.md
  自动化地图/          M-LP 罗盘、M-DD 抖店、M-BY 精选联盟、M-TB 淘宝、M-PD 拼多多；变更记录.md
  模板/                店铺标签卡、链接标准、制作单、决策卡、变更单
  默认值/              选品上架-服装店.md（爆品线等参数）
店铺/<店名>/           主人自己的，更新永不覆盖
  店铺标签卡.md
  链接标准-v<版本>.md
  经营决策库/          D-HP（货盘）、D-ZC（经营政策）卡
  观察表.csv           候选链接的每次记录（罗盘榜单、跨平台快照）
  选品卡/  草稿包/  制作单/  变更单/
```
## 自动化地图的两种
- **只读**：照着走，失败按「自愈」重新找路，只读的新路线试走一遍就能换上。
- **会改东西**（M-DD-102 AI 智能发品、M-BY-001 改佣金）：新路线或第一次走，要主人看过点头才启用；任何时候都停在「提交」前请主人点。
