# 经营决策 · 服装店默认值（主人没想法时先用，用了再改）

> 给人看：第一次算账时，主人没说的就先按这些算，报告里会注明「按默认值」。改了的写进主人自己的经营决策库（`~/.yunjian/abacus/店铺/<店名>/经营决策库/`），这份不动。
> 给 AI：只在主人的经营决策库里没有对应的卡时才用这里的值；用了就在报告「要注意的」里列出来。

| 决策 | 默认值 | 为什么 |
|---|---|---|
| 快递单价（每个包裹） | 3 元 | 常见电商件首重价格的中间值；主人有真实单价立刻替换 |
| 退回来的衣服损耗 | 0（能原样再卖） | 先不扣，主人觉得有洗熨、打折处理再给比例 |
| 寄样单 | 不算销售，单列「达人寄样开支」（成本＋运费） | 以后看每个达人值不值 |
| 税务身份 | 小规模纳税人，按季度申报 | 小店最常见；一般纳税人另算 |
| 企业所得税 | 不在每单利润里扣，月报、年报按净利 × 5% 预估 | 按年汇算，平时只做提醒 |
| 利润分层 | 毛利 → 到手利润 → 净利（三层） | 分别看出货、平台和发货、退货和税吃掉多少 |
