# 算账

## 0. 先读
- 本目录 `算账.py`、`报告.py`；`~/.yunjian/abacus/库/平台规则库/`（结算账单结构、平台服务费、佣金基数、免佣、小额打款、平台扣运费、小规模税费）；主人的 `店铺/经营决策库/`（快递单价、损耗、寄样、税务身份）。决策库没有的项用 `库/默认值/经营决策-服装店.md`，报告里会写「用了默认值」。
- 账单没取：先走 abacus-fetch。成本表 `店铺/底座数据/成本表.csv` 没有：给 `库/模板/成本表模板.csv`，请主人一款一行填；没填完也能先算，缺的单列出来。

## 1. 算
`python3 算账.py --起 YYYY-MM-DD --止 YYYY-MM-DD --店铺 <店铺文件夹>`
- 三层：**毛利**＝收入−成本；**到手**＝毛利−平台服务费−佣金和分成−发货运费；**净利**＝到手−平台扣的退货运费−客服补的运费−客服补偿−偏远地区等店铺费用−达人寄样开支−增值税和附加。
- 它会自己处理：合单一个包裹的运费平摊、商品卡免佣（用账单里的服务费，不按 5% 重算）、结算后退款（收入、服务费、佣金冲平，成本冲回扣掉损耗）、结算前就退掉的单（从资金账单和订单表认出来）、小额打款分运费补偿和客服补偿、寄样单、预估。
- 出到 `店铺/报告/<起>至<止>/`：`逐单账.csv`、`汇总.json` 和一份文字版小结。演练模式下也照算，但只在对话里打印结果。

## 2. 对账（不过不交）
交 abacus-check：`python3 ../abacus-check/对账.py --起 … --止 … --店铺 …`。有「拦」就照它说的修，修好重算；「提醒」写进报告。

## 3. 出报告（必须在对账之后）
`python3 报告.py --起 … --止 … --店铺 …` → `报告.html`。主人没给真实成本或快递单价时加 `--模拟 成本,快递单价`，报告上会写明。
- 顺序固定（主人认过）：三句话 → 四个大数 → 三层账 → 自销和达人 → 按款 → 按达人（含近 6 个月退货率）→ 要注意的 → 逐单明细。
- 三句话由脚本按数据生成；你要补一句解读也行，但**每个数必须是报告里有的**，不另编。

## 4. 交给主人（一条消息）
三句话原样贴出来＋报告附件（`报告.html`，电脑上直接打开）＋逐单账（Excel 能打开）＋「要注意的」里需要主人动手的事（补成本、重复赔付去申诉、默认值要不要改）。主人问某一单、某一款、某个达人，从逐单账里找出来答。

## 不做
不估成本、不猜退货率；不改价、不改佣金、不去申诉、不打款（只给依据，动店的事主人定）；不报税（税只是经营预估，以主人的申报为准）。
