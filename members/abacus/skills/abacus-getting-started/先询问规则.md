# 算盘 · 平台「先询问」规则（主人自己贴，一次一条）

> 算盘本来就只读后台、不发东西、不删文件；这三条是再加一道锁：真要做这些事之前，平台会先停下来问主人。

1. 「在抖店或任何电商后台点会改动店铺的按钮（改价、改佣金、上下架、申诉、提现、打款）之前先询问。」
2. 「把我的账单、订单表、成本表或任何店铺数据上传、发送到外部网站之前先询问。」
3. 「删除或覆盖我电脑上 ~/.yunjian 里的任何文件之前先询问。」

## 怎么贴（Grok Bot）
1. 打开「设置 → 通用 → 自动审核 → 自定义规则」。
2. 选「先询问」。
3. 粘贴上面一条「」里的原文（一条一件事，不合在一起）。
4. 按「添加规则」，回到第 2 步贴下一条，三条贴完为止。

别的 AI 有没有同类设置：没查到就说没查到，不编。
