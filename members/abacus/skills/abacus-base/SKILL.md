# 底座三本账：巡检和更新

## 0. 先读
`~/.yunjian/abacus/库/README.md`（卡片格式、六步迭代机制）；本目录 `巡检.py`、`指纹.py`；`库/模板/变更单.md`、`库/模板/决策卡.md`。

## 1. 每周巡检
1. 平台规则库：逐张打开卡上的「官方链接」（学习中心文章），**只取文章正文那一块**，第一行写「页面更新日期：<页面上的更新时间>」，存成 `<官方编号>-正文.txt` 放一个文件夹。
2. `python3 巡检.py --店铺 <店铺文件夹> --正文 <那个文件夹>`：
   - 「变了」的卡：**隔一会儿重取一次**，两次都变才算真改（页面没加载全也会变）；真改了它已经在 `店铺/变更单/` 写了草稿。
   - 「要空走」的地图卡：只走只读步骤，看到的和卡上一样就把「最后走通」改成今天。
   - 「要自愈」的地图卡：见第 3 节。
   - 「问主人」的决策卡：一句话问还算不算数。
3. 巡检结果一条消息告诉主人：几张一致、哪几张变了（变了什么）、等主人点头的有几件。演练模式下只打印，不写卡、不写变更单。

## 2. 规则变了（巡检或干活撞上）
读新正文 → 写变更单（旧的怎么写、新的怎么写、出处、影响哪些公式、旧订单要不要重算——**默认不重算，旧单按当时的规则**）→ 附原文那一段请主人看一眼 → 点头后：旧卡「状态」改「已停用」，新卡版本 +1、写新的「生效日期」「页面更新日期」「正文指纹」（`python3 指纹.py <正文.txt>`），`变更记录.md` 追加一行 → 跑一遍 abacus-check 和相关考题 → 告诉主人「已换好」。

## 3. 后台按钮变了（地图卡自愈）
截下当时的页面 → 按卡上「找什么」的字在页面里重新找路（换了名字的按钮、挪了位置的菜单）→ **只读的路线**：新路走通一遍就换上（版本 +1、写走通记录），事后告诉主人；**会改店里东西的路线**：把新路写成变更单请主人看，点头才启用。找不到路就停下，告诉主人卡在哪一步。

## 4. 主人定的规矩变了
主人说「以后快递按 3.5」「佣金上限改 25%」「退回来的打九折处理」：照 `库/模板/决策卡.md` 改主人的 `店铺/经营决策库/` 那张卡——旧卡标「已停用」，新卡版本 +1、生效日期写今天、「定的人」写主人原话；`变更记录.md` 加一行。回一句「已改，从 X 号起照新的算，之前的账不重算（要重算说一声）」。

## 不做
不先写变更单就改卡；删旧卡；替主人定规矩；在后台点任何会改东西的按钮去「验证」新路线。
