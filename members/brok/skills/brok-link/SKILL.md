# 一句话设链接

## 0. 先读
- 先读进度文件 `~/.yunjian/brok/进度.md`（没有就照 brok-base/进度模板.md 建；写的时候改对应那一块，不往末尾追加流水）：上回做到哪，有断点就接着做，不从头再问。
- 这款算盘回执的佣金上限（没装算盘看经纪设置卡里主人给的数）。
- 规则卡 R-LM-004（推广策略、优先级、降佣次日 0 点）、R-LM-005（渠道品继承主品佣金、专属只绑 1 位）、R-LM-008（最低 5%）。
- 地图 M-BY-006（指定达人佣金）、M-BY-007（全店定向）、M-DD-103（渠道品）。
- 本目录 `一句话.py`、`佣金闸.py`、`回读核对.py`。

## 1. 解析
`python3 一句话.py "<主人原话>" --出 <谈定单.json>`：缺什么只问什么（退出码 3）。收件信息只进谈定单和发版单。

## 2. 过闸
`python3 佣金闸.py --佣金 <0.16> --回执 <算盘回执>`：超上限或低于 5% 就停，请主人定，不设。主人只说「核心达人照规矩给」时用 `--层级 核心`（不给 --佣金），脚本读主人的规矩、和封顶取低给出能给的数。

## 3. 设（主人一句话就是授权，杨先生 10-31）
- 普通链接：M-BY-006 给这款加指定达人（填 UID）、固定佣金率。
- **渠道品：先照 M-BY-006 设好指定达人佣金，再照 M-DD-103 建「专属达人带货」渠道品绑同一个 UID**——渠道品继承主品佣金、不能单独设（R-LM-005）；主人说「佣金在渠道品里设」要讲清这一点。
- 建专属渠道品时：前缀最多 6 个汉字；**每个 SKU 的渠道库存默认 0，要分配**（问主人给这位分多少件，没说就先按谈定的件数×10 提议、请主人点头）。
- 固定佣金率只能填 5-80 的整数，`佣金闸.py` 会拦小数。
- 全店：M-BY-007 按 UID 绑定（只对设了全部达人佣金的商品生效，优先级低于指定达人）。
- 降佣：说清**次日 0 点才生效**（R-LM-004）。
- 平台弹「始终询问」就请主人点一下。
- **后台在哪操作**：用这台 Bot 自带浏览器里主人登录好的抖店／精选联盟；没登录就请主人登录（扫码主人自己扫），登不上或主人不在：停在谈定单，把要设的内容（商品、UID、佣金、渠道品类型、库存）列成一张清单给主人自己照着设，设完让主人回一句，回来再回读核对（Bot 实测自报 10）。

## 4. 回读、回报
后台读回来抄成 json，`python3 回读核对.py --谈定单 … --回读 …`：一致才往下（合作单步「⑥链接已设」）；不一致告诉主人哪一项。回报一句：给谁、哪款、多少佣金、什么链接、几时生效；渠道品把「复制链接」给主人转达人。然后交 brok-sample 出发版单。

做完写进度：这次做到哪、下一步、等主人定的写回 `~/.yunjian/brok/进度.md`，不靠聊天记录。
