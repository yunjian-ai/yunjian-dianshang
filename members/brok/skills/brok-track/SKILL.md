# 合作单和今日待办

## 0. 先读
- 先读进度文件 `~/.yunjian/brok/进度.md`（没有就照 brok-base/进度模板.md 建；写的时候改对应那一块，不往末尾追加流水）：上回做到哪，有断点就接着做，不从头再问。
- `合作单.json`、样品管理待审核（brok-sample 抄的表）；平台「我的达人库」状态（M-BY-004，对不上以平台为准）。
- 默认值里的时限（`库/默认值/达人推广-服装店.md`），主人改过的在经营决策库。
- 本目录 `合作单.py`。

## 1. 九步（一张合作单＝一位达人 × 一款）
①候选 → ②已建联 → ③聊中 → ④转人工 → ⑤谈定 → ⑥链接已设 → ⑦发版单已出／样衣已发 → ⑧已签收→上播 → ⑨出单→复盘。每步做完改「步」、记日期。

## 2. 今日待办
`python3 合作单.py --合作单 <合作单.json> --申样 <待审表> --消息 <合作消息.json> [--今天 …]`（消息会分好类并进待办：拒绝、转人工、谈佣金、夹带、申样对不上）：按急排，默认窄表（≤5 列，说明在表下），电脑上加 `--宽`。没有合作单就说要去哪看（合作消息、样品管理、达人库），**不编待办**。

## 3. 复盘
上播 3 天出单少于 5 单：把这位的出单数、佣金交给算盘算利润（没装算盘就写「没装算盘，利润没算」、给料单：出单数、成交额、佣金、成本、退货，**不心算**）；复盘话术、款、价，写进合作单「已复盘」。

做完写进度：这次做到哪、下一步、等主人定的写回 `~/.yunjian/brok/进度.md`，不靠聊天记录。
