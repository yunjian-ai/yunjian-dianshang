# 经纪 · 平台「始终询问」规则（主人自己加，一次一条）

> 经纪设佣金、建渠道品、审样，主人一句话交代了就算授权；这几条是再加一道锁：真要做这些事之前，平台会先停下来问主人一下，主人点一下就过。和货郎、算盘是同一套，已经加过的不用重复加。

1. `在抖店或任何电商后台点会改动店铺的按钮（发布商品、改价改库存、改佣金和推广计划、建渠道品、审核样品、上下架、申诉、提现、打款）`
2. `把店铺数据、达人联系方式、收件地址上传、发送到外部网站`
3. `删除 ~/.yunjian 文件夹里的文件或文件夹`
4. `修改任何账号的资料、密码、安全或权限设置`

## 怎么加（Grok Bot，主人自己点）
1. 点左下角头像进「设置」，左边选「权限」，确认「自动审核」开着。
2. 点「始终询问」右边的「添加规则」。
3. 在「适用于」框里粘贴上面一条原文（一条一件事；写的是「什么操作」，不用写「先询问」，这一栏本身就是询问）。
4. 点白色的「添加规则」，回到第 2 步加下一条，加完为止。

- 这几条整个账号的 Bot 共用：已经有一样意思的规则（货郎、算盘带主人加过）就只补第 1 条里新加的「建渠道品、审核样品」。
- **不要加「在精选联盟给达人发消息」**：第一句是模板点过头以后自动发的，加了会每条都停；发消息的量由 `brok-reach/发送节流.py` 管。
- 不要加「覆盖 ~/.yunjian 里的文件」：每个 Bot 干完活都要写回进度文件，会一直停下来问。
- 别的 AI 有没有同类设置：没查到就说没查到，不编。
