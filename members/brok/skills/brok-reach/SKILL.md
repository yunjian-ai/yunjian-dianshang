# 第一句、回消息、转人工

## 0. 先读
- 先读进度文件 `~/.yunjian/brok/进度.md`（没有就照 brok-base/进度模板.md 建；写的时候改对应那一块，不往末尾追加流水）：上回做到哪，有断点就接着做，不从头再问。
- 这款素材包（必须过了 `brok-kit/查素材包.py`）、百问百答库、经纪设置卡（已授权模板、每天上限）。
- 地图 `库/自动化地图/M-BY-003`（合作消息）；规则卡 R-LM-007（IM 规矩、程序风险）、R-LM-006（建联额度、拒绝邀约）。
- 本目录 `查话术.py`、`发送节流.py`。

## 1. 第一句
- 四样齐：**主推款、证据（带出处的数）、政策（佣金、样品、运费险）、联系途径**（正文写「点下方联系方式」，用后台「发送联系方式」按钮发，不在正文写手机号微信号）。
- 第一句里引用的数**照素材包里的出处原样写**，不自己补；对标款的数要说清是「对标款」「对标店」的，不写成本店（考试 J4，10-31）。
- **新达人的第一句是「邀约带货」卡片**（达人广场「在线沟通」打开，地图 M-BY-003 第 0 步）：邀约信息 ≤150 字；专属权益照政策勾（有专属高佣才勾「专属高佣」、支持免费申样才勾「免费申样」）；联系方式填经纪设置卡里主人给的手机号／微信；专属推荐商品选这款。**达人没回或拒绝，平台 60 天内不许再邀约**——没有「3 天再跟」这回事（实测 10-31）。
- `python3 查话术.py --第一句 "<文本>" --素材包 <素材包.json>` 过了才算能用；≤150 字（邀约信息上限）；没有极限词。
- **模板没在经纪设置卡「已授权模板」里：只起草，请主人点头一次**；点过头的同模板以后自动发。

## 2. 发之前过节流（`发送节流.py` 只读检查，不发消息）
`python3 发送节流.py --记录 <发送记录.csv> --达人 <编号> --类型 第一句|跟进 --合作单 <合作单.json> --额度 <额度.json>`
- 不能发（每天上限到了、间隔不够、跟满次数、达人拒绝、本周额度用完）就不发，告诉主人原因和什么时候能发；额度用到八成提醒主人。
- 能发：照 M-BY-003 在合作消息里发，发完加 `--记一条 --模板 <名>`；合作单步改「②已建联」、记第一句日期。
- 浏览器照人的节奏操作，不批量刷（R-LM-007，杨先生 10-31）。

## 3. 回消息（每天定时看，也可主人叫）
| 类 | 怎么做 |
|---|---|
| 申样 | 交 brok-sample（72 小时内审） |
| 谈佣金 | 问 UID，或转主人；佣金要过佣金闸 |
| 要联系方式／已发送联系方式 | **当场提醒主人加微信接手**（合作单步「④转人工」） |
| 合作邀约、问问题 | 库里有的照 `brok-kit/百问百答.py` 原话答；没有的不编，转主人 |
| 拒绝（「商品不太适合我」、设了拒绝邀约） | 合作单标拒绝，不回、不再发 |
转主人的提醒写清：哪位达人、匹配分、聊到哪、建议怎么接。主人答了库外问题就入库。

做完写进度：这次做到哪、下一步、等主人定的写回 `~/.yunjian/brok/进度.md`，不靠聊天记录。
