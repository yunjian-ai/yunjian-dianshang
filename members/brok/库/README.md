# 经纪的底子 · 三本会长的账（格式同算盘、货郎，2026-10-31）

> 给人看：经纪的底子和算盘、货郎同一套格式：**A 平台规则库**（官方规则，一条一张卡）、**B 自动化地图**（后台每一步怎么点）、**C 经营决策库**（主人定的规矩，放在主人自己的店铺文件夹里）。规则变了、按钮挪了、规矩改了，都先写变更单再改，旧的不删。脚本里的线和上限一律从账里读，不写死。
> 给 AI：卡的格式、变更单六步照算盘 `库/README.md`（同一套）；这里只写经纪自己的东西。R-LM-001、R-SP-006、M-BY-001 是从货郎原样带的一份，货郎改了这里跟着换。

## 自动化地图的两种
- **只读**：照着走，失败按「自愈」重新找路，只读的新路线试走一遍就能换上。
- **会改东西或对外**（M-BY-003 发消息、M-BY-005 审样、M-BY-006 指定达人佣金、M-BY-007 全店定向、M-DD-103 渠道品）：新路线或第一次走，要主人看过点头才启用；主人一句话交代的设链接算授权，过佣金闸、信息齐才提交，提交后回读。
