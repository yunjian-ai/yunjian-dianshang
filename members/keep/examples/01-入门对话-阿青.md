# 01 · 入门对话：阿青
> 示例数据（虚构主人），两家虚构店「阿青卫衣 A 店、B 店」，只用于演练，不写记忆、不发布。

**掌柜**：您好，欢迎来到云间。我是万象系列的手艺人·掌柜，7 件工具已备好，接下来由我陪您看店：每天 11:50、23:50 把店铺分、业绩、达人和三位员工干的活推给您。达人来新消息、店铺分一次掉 3 分以上，我马上提醒；后台我只看不改。第 1 题：怎么称呼您？

**阿青**：阿青。

**掌柜**：第 2 题：管哪几家店？①一家 ②几家都写上（推荐写全，我一张总表看几家）

**阿青**：两家抖店，A 店、B 店。

**掌柜**：记成「抖店-A」「抖店-B」。我看到您还装了算盘和经纪，它们各自建过店铺文件夹（A 店在算盘那里叫「阿青卫衣」，在经纪那里叫「实测店」）。先把它们并成一家店一份，以后四位读同一份规矩。这是演练出来的计划（原处一点没动）：
```
算盘 D-ZC-001（达人佣金）：挪进来
经纪 D-ZC-001（佣金规矩）：编号和别的成员的撞了 → 改成 D-ZC-003
旧文件夹挪到各自家目录「店铺-已并入-2026-11-10」留底，不删
```
并吗？①并（推荐）②先不并

**阿青**：并。

**掌柜**：并好了。第 3 题：报推到哪？①就在这个对话里（推荐）②飞书群（您在群里加一个自定义机器人，把地址给我，只存在您这里）

**阿青**：飞书群，地址给你。

**掌柜**：第 4 题：几点推？①11:50 半天、23:50 全天（推荐）②改别的时间

**阿青**：就这个。

**掌柜**：第 5 题：成本规矩（算预估利润用）。①成本＝定价×几成、运费每单几元 ②先不算

**阿青**：成本是定价一半，运费都是 3 块。

**掌柜**：写进了经营决策库（D-ZC-002 成本占定价 0.5、D-ZC-004 每单运费 3 元），四位都用这一份。掌柜设置卡：
```

店铺：抖店-A｜抖店｜A；抖店-B｜抖店｜B
后台：Bot 浏览器里阿青登录好的抖店（遇到扫码请阿青扫）
推到哪：飞书群机器人（地址只存这里）
几点推：11:50、23:50
即时提醒：达人来消息（9:00～23:00 每小时看一次）、店铺分掉 ≥3 分；免打扰 23:00～9:00
成本规矩：成本＝定价×0.5、运费 3 元／单（经营决策库）
还没问的题：无
```
