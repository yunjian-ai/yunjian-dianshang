# 掌柜的底子

## 0. 先读
- 先读进度文件 `~/.yunjian/keep/进度.md`（没有就照 keep-base/进度模板.md 建；写的时候改对应那一块，不往末尾追加流水）：上回做到哪，有断点就接着做，不从头再问。
- 进度文件 `~/.yunjian/keep/进度.md`（没有照本目录 `进度模板.md` 建，改对应那一块）。
- `库/README.md`（文件夹、四位共用的店铺根目录）；卡的格式、变更单六步同算盘一套。
- 本目录：`底子.py`（参数、出表、打码、短名）、`读页面.py`、`汇总.py`、`统一店铺.py`、`决策卡.py`、`回执.py`、`指纹.py`。

## 1. 读后台（只读，照人的节奏）
| 存成 | 路线 |
|---|---|
| 首页.txt＋首页-涨跌.json | M-KP-002 抖店首页（待办、近 7 日达人） |
| 体验分.txt＋体验分-涨跌.json | M-KP-001 商家体验分 |
| 罗盘首页.txt、罗盘首页-合作.txt | 电商罗盘首页「实时」，再切「合作」（看达人带了多少），读完切回「全店」 |
| 商品榜.txt | 电商罗盘「商品 → 商品列表」切「实时」 |
| 合作消息.txt | M-BY-003 第 3 步（只看左栏，不点进会话） |
- 涨跌.json：「较昨日／较前1日」的方向只在页面元素上（class 带 up/down、或红绿颜色），文字里只有百分比；Bot 自己看页面时照页面箭头填 `[{"值": "43.94%", "方向": "down"}]`。
- 存进 `店铺/<店>/掌柜/后台/<日期>/<时刻>/`，跑 `python3 读页面.py <文件夹> --店铺 <店名>` 出 `后台数.json`；认不出的写进「没取到」，照「自愈」改路线卡。
- 罗盘、体验分、合作消息页的数是实时的、没结算；真实利润以算盘为准。

## 2. 统一店铺（装了两位以上员工时做一次）
`python3 统一店铺.py --改名 <旧名>=<新名> … --演练` 先看计划（在临时目录里照做一遍），主人点头再去掉 `--演练`。一家店一个名字（如「抖店-A」）、一份经营决策库；只挪不删，撞号的卡改号并记进变更记录，旧文件夹挪到 `<员工家目录>/店铺-已并入-<日期>/`。并完看一眼经营决策库：同一件事（如佣金）有几张都「生效」的，列给主人定哪张为准，不自己挑（Bot 实测 10-31）。

## 3. 主人定的规矩
主人说「掉 2 分就提醒我」「12 点推」「这家店成本按定价一半算」：用 `决策卡.py --类 KP|ZC --标题 … --原话 「…」 --参数 名=值`（参数名照 `库/默认值/看店-服装店.md`），不手写卡。成本规矩（成本_占定价）、快递单价写一次四位都用。

## 4. 每周巡检、自愈
平台规则库每张卡取官方正文跑 `指纹.py` 比；路线卡页面上找不到写的字：「连续失败」+1，照现在的页面重新找路，只读路线试走一遍通了就换上，告诉主人一句。掌柜的路线全是只读。

## 5. 浏览器守三条
只在主人登录好的浏览器里、照人的节奏看，不碰接口、不批量刷页面；遇到扫码、验证码、异地登录停下请主人；看完不留打开的页面。

做完写进度：这次做到哪、推了什么、下一步、等主人定的写回 `~/.yunjian/keep/进度.md`，不靠聊天记录。
