# 掌柜的底子 · 三本会长的账（格式同算盘、货郎、经纪，2026-10-31）

> 给人看：掌柜的底子和另外三位同一套格式：**A 平台规则库**（官方规则，一条一张卡）、**B 自动化地图**（后台每一页怎么看，掌柜只看不改）、**C 经营决策库**（主人定的规矩，四位共用一份，放在店铺文件夹里）。规则变了、页面挪了、规矩改了，都先写变更单再改，旧的不删。脚本里的线一律从账里读，不写死。
> 给 AI：卡的格式、变更单六步照算盘 `库/README.md`（同一套）；R-LM-007、M-BY-003 是从经纪原样带的一份，经纪改了这里跟着换。

```

  自动化地图/              M-KP-001 体验分页、M-KP-002 首页实时、M-BY-003 合作消息（只读部分）
  模板/                    推送模板、决策卡、变更单、后台数格式

~/.yunjian/店铺/<店名>/    四位共用，主人自己的，更新永不覆盖
  经营决策库/              一份，四位都读（D-ZC 经营政策、D-HP 货盘、D-DR 达人、D-KP 看店）

  （另外三位各自的文件：账单、报告、在售款、合作单……）
```
